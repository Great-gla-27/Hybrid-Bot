# Demo Artifacts

This folder contains demonstration materials for the HybridTrendBot project.  
They illustrate what a typical backtest would produce when run in cTrader.

- **backtest_equity_curve.png** → Example equity curve (placeholder image, replace with your own screenshot).  
- **backtest_report.html** → Example backtest report file (HTML export from cTrader).  

These files are placeholders. Replace them with real outputs after running your own backtests.
